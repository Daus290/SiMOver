4. PANDUAN PENGOPERASIAN SISTEM (SATU PERINTAH)
--------------------------------------------------------------------------------
Sistem telah dilengkapi dengan automasi startup cerdas. Pengguna tidak perlu lagi
membuka banyak terminal manual:

1. MENYALAKAN SISTEM:
   Buka terminal PowerShell di folder proyek dan jalankan:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\start-system.ps1

   Perintah ini otomatis:
   a. Memeriksa ketersediaan PHP dan FFmpeg portabel.
   b. Menyalakan database MySQL/MariaDB XAMPP port 3306 di latar belakang jika belum jalan.
   c. Menyalakan web server CodeIgniter 4 (port 8080) di latar belakang (tanpa popup jendela).
   d. Menguji koneksi ke NVR kantor (10.0.1.3:8554).
      - Jika di jaringan kantor: otomatis menyalakan seluruh 16 background relay CCTV.
      - Jika di luar kantor / hotspot HP: web lokal tetap menyala normal dan relay dilewati agar tidak membebani memori.
   e. Mengembalikan kontrol terminal ke pengguna secara instan.

2. MEMERIKSA STATUS KAPAN SAJA:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\start-system.ps1 -Action status

3. MENGHENTIKAN SELURUH SISTEM:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\start-system.ps1 -Action stop

4. MEMULAI ULANG SISTEM:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\start-system.ps1 -Action restart
